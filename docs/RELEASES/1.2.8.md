# Axiom 1.2.8

## Release status

This is an unsigned Windows x86_64 release candidate. Windows may show a SmartScreen warning
until a future release is Authenticode-signed. Verify the GitHub release checksum before running
an artifact. Axiom is a native Rust browser executable; it does not bundle Chromium or a WebView.

## Highlights

- A dark **Orbit Rail** chrome: a distinct trusted tab rail, compact navigation controls, and an
  Axiom connection mark that stays outside web-controlled content.
- Persistent and private profiles, tabs, history, bookmarks, sessions, cookies, Web Storage,
  Fetch/XHR foundations, a profile-owned network/cache stack, and trusted diagnostics pages.
- XML/XHTML realms, same-origin frame document proxy foundations, XML XHR documents, and focused
  WPT improvements for CDATA, element namespaces, and `Document.contentType`.
- No AI integration, telemetry, analytics SDK, account requirement, or private-data upload path.
  See `docs/PRIVACY.md` for the exact local-data and third-party-network scope.

## Install

1. Download `Axiom-Setup-1.2.8.exe` when supplied by the signed release, or use the portable
   `Axiom-1.2.8-windows-x86_64.zip`.
2. Run the installer. It installs per-user under `%LOCALAPPDATA%\Programs\Axiom` and creates
   Start Menu and Desktop shortcuts; no administrator rights are required.
3. Start Axiom. `Ctrl+L` focuses the omnibox; `Ctrl+T` creates a tab; `Ctrl+Shift+T` restores one.

## Known limits

This release is not Firefox- or Chrome-compatible. The core pipeline is real and tested, but the
HTML, DOM, CSS, layout, JS, accessibility, process sandboxing, and web-API surfaces remain under
active compatibility development. `data:` iframe documents and `javascript:` iframe navigation
are not implemented. See `docs/REALITY.md` and `docs/COMPATIBILITY.md`.
