# Axiom branding

## Official mark

`assets/axiom-mark.svg` is the official Axiom logo: an **orbital A**. Its circular orbit represents
the browser's controlled execution boundary; the A represents an independently owned engine.

The mark uses Axiom Night (`#111827`), Orbit Blue (`#447AFF`), and Signal White (`#F3F7FF`). The
same geometry is generated into the Windows executable resource and passed to the native window at
runtime, so Axiom does not depend on an external image file to show its desktop icon.

## Use

Use the supplied SVG without recoloring, stretching, or adding third-party browser marks. Keep
clear space equal to at least one quarter of the mark's width. The mark identifies Axiom; it does
not imply compatibility with or affiliation with Chromium, Firefox, Google, Mozilla, or any other
browser vendor.
